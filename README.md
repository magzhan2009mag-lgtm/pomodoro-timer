# Помидор

Pomodoro-таймер на Flutter: сессии фокуса и перерывы, круговой прогресс в виде
циферблата кухонного таймера, звук по окончании и счётчик «помидоров» за день.
Работает на Android, Windows и в браузере.

## Что внутри

| Тема | Где смотреть |
| --- | --- |
| **Таймеры** | `lib/pomodoro_controller.dart`. Время считается от сохранённой метки окончания, а не тиками, поэтому таймер не «уплывает» в фоне и переживает перезапуск приложения. |
| **Анимации** | `lib/widgets/timer_dial.dart`: дуга на `CustomPainter` + `Ticker` (60 fps), цифры-«одометр» на `AnimatedSwitcher`, «вдох» и волна при завершении. Плавная смена цвета экрана, `AnimatedIcon` play/pause, скользящая плашка режима, «выскакивающие» помидоры в счётчике. Учитывается системная настройка «уменьшить движение». |
| **Сохранение данных** | `shared_preferences`: настройки, статистика по дням (последние 60 дней) и состояние текущего таймера. Если сессия закончилась, пока приложение было закрыто, она засчитывается при следующем запуске. |
| **Звук** | `assets/sounds/chime.wav`, трёхнотный колокольчик (синтезирован, без сторонних файлов), играется через `audioplayers`. |

## Управление

- Пробел: старт / пауза
- R: сбросить текущую сессию
- N: пропустить (сессия не засчитывается)

## Запуск

```sh
flutter pub get
flutter run -d chrome      # или windows / android-устройство
flutter test               # 17 тестов: логика таймера, циклы, сохранение
```

Шрифты: [Unbounded](https://fonts.google.com/specimen/Unbounded) и
[Onest](https://fonts.google.com/specimen/Onest), лицензия SIL OFL
(`assets/fonts/OFL-*.txt`).
